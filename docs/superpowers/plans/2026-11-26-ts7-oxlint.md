# TypeScript 7 + Oxlint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the generated TypeScript client's dev toolchain from TypeScript 6 + ESLint/typescript-eslint to TypeScript 7 + Oxlint, and lint in CI and the done gate.

**Architecture:** `regenerate_ts.py` owns the client's `package.json` and config files, so the change is made there, then `typescript-client-generated/v3.0.0` is regenerated from its own committed spec. The TS 6 hold is removed from Renovate and the drift checker. CI and `done_gate.sh` gain a lint step.

**Tech Stack:** Python 3.11+ (uv, ruff, pytest), Node 24 via nvm, TypeScript 7, Oxlint 1.x, Vitest 5, openapi-generator 7.x.

**Spec:** `docs/superpowers/specs/2026-11-26-ts7-oxlint-design.md`

## Global Constraints

- devDependencies exactly: `typescript` `^7.0`, `oxlint` `^1.95`, `vitest` `^5.0`. No `@eslint/js`, `eslint`, `typescript-eslint`.
- `"lint": "oxlint test"`; generated `src/` is not linted.
- No change to the published package's API or emitted formats: CJS `dist/` + ESM `dist/esm/` with `.d.ts`.
- No spec change: regenerate only from `typescript-client-generated/v3.0.0/tmi-openapi.json` as committed. Do not run `regenerate_all.py` (it downloads upstream specs and opens a PR).
- No npm release, no Python/Go changes, no type-aware lint (issue #96).
- Done gate: `bash done_gate.sh` (needs `export NVM_DIR=~/.nvm; . "$NVM_DIR/nvm.sh"` first).

## Review Focus

1. Regenerating over an existing client that still has `eslint.config.mjs` must delete it, not leave a dead config (test in Task 1).
2. A lint failure during regeneration must count as an issue (exit 2), not be skipped; the old `LINT_TS7_MARKER` skip path must be gone (test in Task 1).
3. TS 7 emit must keep the same `dist/` file set and equivalent `.d.ts` (comparison step in Task 1).
4. `check_regen_drift.py` with an empty `HOLDS` must still pass live and its tests (Task 1).
5. CI lint must run in every committed TS version directory and fail the job on findings (Task 2).
