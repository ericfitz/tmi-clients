# ADR 0006: API 3.0.0 clients replace 2.2.0

- **Status:** Accepted
- **Date:** 2026-11-22
- **Decision by:** Eric Fitzgerald (human-made architectural decision)

## Context

tmi `main` moved the API schema from 2.2.0 to 3.0.0. Compared with 2.2.0, the API surface changes are:

- a new `GET /api/server-info` operation (`ServerInfoResponse`, on `ConfigurationApi`);
- new enums: `SurveyBase.status` (`active`, `inactive`, `archived`), the
  `SurveyResponse` / `SurveyResponseListItem` status (`draft`, `submitted`,
  `needs_revision`, `ready_for_review`, `review_created`), and `ThreatModelInput.framework`
  (`CIA`, `STRIDE`, `LINDDUN`, `DIE`, `PLOT4ai`, or empty), which replaces its pattern;
- tighter `maxLength` limits (`AdminGroup`, `AdminUser`, `ThreatBase`, `EmbeddingIngestionItem`,
  `UsabilityFeedbackInput`);
- `JsonPatchDocument` gains `from`, and `path` must now be non-empty (`^(/[^/]*)+$`).

`versions.json` lists only `main`, so regenerating produces `v3.0.0` / `v3_0_0` client
directories and prunes `v2.2.0` / `v2_2_0`.

## Decision

Regenerate for API 3.0.0 and **drop the 2.2.0 clients** (directories pruned), following
ADR 0005. There are no further 2.2.x client fix releases, because ADR 0003 needs the nearest
same-minor directory and none remains for 2.2. Packages already published (PyPI, npm,
Go proxy) are unaffected.

The new enums are enforced like every other non-error enum. The ADR 0005 exemption
still covers only `Error.error` and `OAuthError.error`.

## Consequences

- The Go import path changes to `github.com/ericfitz/tmi-clients/go-client-generated/v3_0_0/v3`.
- Python and TypeScript packages move to 3.0.0 (`tmi-client`, `@tmi-dev/client`).
- A 3.0.0 client rejects survey statuses or frameworks outside the enums above, so a later server
  that adds values needs a regenerated client.
